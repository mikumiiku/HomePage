# 士兵模型

- 文件：soldier.glb（2.1 MiB）
- 来源：Three.js r160 示例 https://github.com/mrdoob/three.js/blob/r160/examples/models/gltf/Soldier.glb
- 原模型与动画：Mixamo Vanguard，Three.js 示例署名 https://threejs.org/examples/webgl_animation_skinning_blending.html
- 使用说明：Adobe Mixamo FAQ 允许角色与动画用于个人或商业游戏：https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html
- 本文件作为本游戏的内嵌角色资源使用，不作为独立素材包出售。
- 动画：Idle / Walk / Run / TPose；游戏使用独立骨骼实例和 Idle / Walk 动画。
